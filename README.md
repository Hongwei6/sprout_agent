# 萌芽（sprout_agent）

萌芽是一个仿豆包风格的 AI 助手前端项目，包含响应式聊天界面、快捷提问和本地会话历史。

> 当前版本是前端原型，尚未连接 AI 模型服务。发送的内容仅保存在当前浏览器，并会明确提示模型服务未接入。

## 本地运行

无需安装依赖。使用 Python 启动静态服务器：

```sh
python3 -m http.server 8000
```

打开 <http://localhost:8000>。

## 当前功能

- 桌面与移动端聊天布局
- 快捷提问、回车发送（Shift+Enter 换行）
- 浏览器本地保存与切换会话
- 清空当前会话

## 后续接入

需要配置服务端 AI 接口后，才能实现模型回复。不要把模型 API 密钥放进浏览器端代码。
